# 🚫 Illegal Parking in Portugal

A public map of illegal parking reports in Portugal, crowdsourced via the [Denúncia Estacionamento](https://denuncia-estacionamento.app/) app.

**→ [View live map](https://canales.github.io/illegal-parking-portugal)**

---

## What this map shows

- **Where** reports are concentrated (heatmap and street-level view)
- **What types** of infractions dominate each area
- **How the problem has grown** since 2020

Data is reported by citizens through the [Denúncia Estacionamento](https://denuncia-estacionamento.app/) app and served anonymously via its [public API](https://denuncia-estacionamento.app/api.html).

---

## Why this exists

Illegal Parking in Portugal and particularly in large cities, with large vehicle fleets, is an endemic problem. 

Lisbon City Hall launched a [public survey on illegal parking and pedestrian mobility](https://informacao.lisboa.pt/agenda/municipal/estacionamento-abusivo-e-mobilidade-pedonal) in March 2026 — but five years of crowdsourced evidence already shows the scale of the problem. This map makes that evidence visible and shareable.

## Architecture

```
GitHub Actions (weekly)
    └── fetch_data.py    → fetches API  → data/infractions.geojson
    └── street_match.py  → OSM snap     → data/streets_matched.geojson
        └── GitHub Pages serves index.html + GeoJSONs (free)
```

Infrastructure cost: **zero**. Everything runs on GitHub.

---

## Repository structure

```
├── index.html                       # MapLibre GL map
├── data/
│   ├── infractions.geojson          # Point data (generated by fetch_data.py)
│   └── streets_matched.geojson      # Street-level aggregation (generated by street_match.py)
├── scripts/
│   ├── fetch_data.py                # Fetches data from the API
│   └── street_match.py             # OSM map matching via pyrosm
└── .github/workflows/
    └── update_data.yml              # Weekly automation
```

---

## Running locally

```bash
# Install dependencies
pip install pyrosm geopandas scipy shapely

# Fetch latest data from the API
python scripts/fetch_data.py

# Street matching — Lisbon only (fast, good for testing)
python scripts/street_match.py --city lisbon

# Street matching — full Portugal (~20 min, ~400MB download)
python scripts/street_match.py
```
